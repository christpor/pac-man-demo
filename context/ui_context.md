# 🎨 UI & Design Context: Pac-Man Demo

## Game board Visual Tokens
- **Background:** Deep black canvas (#000000) for authentic retro feel.
- **Maze Walls:** Deep blue lines (#0000ff) representing the maze boundaries.
- **Pac-Man:** Bright yellow circle (#ffff00) with dynamic mouth opening arcs.
- **Ghosts:**
  - Blinky (Red): #ff0000
  - Pinky (Pink): #ffb8ff
  - Inky (Cyan): #00ffff
  - Clyde (Orange): #ffb852
  - Frightened State: Deep blue (#0000ff) or flashing white (#ffffff).

## UI Typography
- **Font Stack:** Clean, modern monospace font families (e.g. Courier New, Press Start 2P fallback) for retro scoring visuals.
- **Contrast:** High contrast white score layouts.

## Mobile Layout Boundaries
- Responsive Canvas scaling: Ensure canvas fits mobile screens with dynamic scale calculations.
- Display on-screen touch D-Pad controls or swipe directions overlay.
